# ☕ Cup2Eat — Premium Edible Cups E-Commerce & Operations Platform

> **"Eat Your Drink! ☕🍨 A Delicious & Sustainable Innovation."**

Cup2Eat is an animated, realistic, and production-grade web application built with **React**, **Vite**, and **Tailwind CSS**. It showcases 100% edible, biodegradable, zero-waste wafer cups designed for hot chai, barista coffees, gelato, and desserts, complete with an interactive 3D tasting simulator, direct customer ordering, and a merchant admin management suite.

---

## 🌟 Key Features

- **☕ 3D Taste & Sip Simulator:** Interactive wafer cup simulation where users can pick flavours (*Rich Cocoa Chocolate*, *Sweet Vanilla*, *Royal Desi Elaichi*), select beverages (*Kadak Chai*, *Cappuccino*, *Gelato*), trigger liquid pouring, and take crunchy bites with real-time leak-proof countdown.
- **📦 Direct Wholesale & Retail Ordering:** Featuring the signature **₹3,999 for 396 Cups** master carton with free shipping across India.
- **⚡ Dual Checkout Channels:**
  - Direct WhatsApp order formatting with itemized payload.
  - Full online checkout simulator with dynamic UPI QR code generator, Cash on Delivery, and instant printable invoices.
- **📊 B2B Café Volume Calculator:** Instant tiered quote generator for cafes, restaurants, and catering events (500 to 25,000+ cups/mo).
- **🌱 Measurable Eco-Impact Calculator:** Computes single-use plastic waste eliminated, CO₂ offset, and trees saved.
- **🛡️ Authentic FSSAI & Award Compliance:** Govt. of UP FSSAI Registration `#22725101003467` certificate inspection modal, IPEM 1st Prize recognition, and Startup Mahakumbh showcase.
- **🛠️ Merchant Admin Operations Panel:** Live control dashboard with order fulfillment pipeline, inventory stock updater, B2B lead pipeline, and real-time announcement ticker editor.

## 🚀 Quick Start

### 1. Installation
```bash
git clone https://github.com/yatindradhurwe/cup2eat.git
cd cup2eat
npm install
```

### 2. Run Locally
```bash
npm run dev
```
Open [http://127.0.0.1:5173/](http://127.0.0.1:5173/) in your browser.

### 3. Build for Production
```bash
npm run build
```
